# 球球 设计规范

[查看 Figma 原型](https://www.figma.com/design/VIk4IyS8BLG0YSm3lpXi3R?node-id=9-29)

Android 交互稿采用 390 × 844 画板，按钮强调色 `#00A878`，对话区内嵌可点击选项与结构化商品卡。选规格和购物车是关键动作，应有清晰反馈。

| 状态 | 界面行为 | 验收 |
|---|---|---|
| 需求宽泛 | 在对话中插入少量澄清选项，保留已给条件 | Q02-TC01 / Q02-TC02 |
| 接收流式回答 | 保留当前会话，卡片事件独立渲染 | Q01、Q06 |
| 无匹配或断流 | 说明状态并允许改条件/重试，避免把部分输出当完成 | Q01-TC02、Q03-TC02 |
| 查看与加购 | 详情选 SKU，确认后展示同一件商品的本地购物车状态 | Q06、Q07 |

以上为对现有原型的设计记录。
